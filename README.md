## 三、LXC 还是 KVM，怎么选

这是买 ByteVirt 香港 HKT VPS 时最常被问到的选择题。两套架构在官网是分开列的，价格也不一样。

**LXC（容器虚拟化）**

- 资源共享程度更高，开销小，价格更便宜。
- 隔离性弱一些，内核与宿主共享。
- 适合：极致省钱、跑轻量 Linux 服务、对内核没有特殊要求。

**KVM（全虚拟化）**

- 完整虚拟化，隔离性和兼容性都更好。
- 可以自定义内核、跑更复杂的系统配置。
- 价格比 LXC 略高，但整体更稳。
- 适合：想要更稳定的环境、需要折腾系统层面、对隔离性有要求。

站长和不少测评者的共识是：**差价就几毛到一美元，优先选 KVM**。如果你只是想花最少钱试个水，那 LXC 入门款也够用。

## 七、NAT 端口怎么用，新手最容易卡的点

很多人买完 NAT VPS 第一反应是"我 SSH 怎么连不上"——因为你得用分配给你的端口，不是默认 22。

ByteVirt 官方给的规则是：

- 每台 NAT VPS 分配 20 个 IPv4 端口，比如 30101-30120。
- SSH 默认监听 22，但公网访问要改成你分配的端口，比如 `ssh -p 30101 root@你的公网IP`。
- 建站、反向代理同理，80/443 这类常用端口在 NAT 共享 IP 上不可用，得用分配端口。
- IPv6 没有这个限制，原生 IPv6 可以直接用标准端口。

调试顺序记住一句话：**服务状态 → 防火墙 → 端口映射 → 网络路由**。99% 的"Connection Refused"都是因为服务没监听或者没监听对端口。
